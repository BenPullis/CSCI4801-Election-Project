Detailed Description

A class for generating audit reports for elections.

This class provides functionality to create an audit report file containing election details, including a header with the current date.

void AuditReport::generateReport ( const std::vector< std::string > & details)

Generates an audit report file with the provided details.

This method creates a file named "audit_report.txt" and writes a header including the election title and current date, followed by the provided details. If the file cannot be opened, an error message is printed to stderr.
